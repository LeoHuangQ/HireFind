# HireFind Backend

Simple Node.js backend API for the HireFind project.

## Installation

```bash
npm install
```

## Running the Server

**Development mode** (with auto-reload):
```bash
npm run dev
```

**Production mode**:
```bash
npm start
```

The server will run on `http://localhost:3000`

## API Endpoints

- `GET /` - Welcome message
- `GET /api/health` - Health check endpoint
